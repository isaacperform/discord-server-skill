# Operating notes for this server

> Claude reads this before working on this server. Edit it to fit your server.

- Tone: friendly and short. One emoji at the start of a line at most.
- @everyone pings: only in announcements, only when the owner asks.
- Inviting testers: `invite --note "Name (where they came from)"`. The owner sends the link personally.
- Changelog format:

  ```
  ### 🚀 YYYY-MM-DD release
  - ✨ New: …
  - 🛠️ Improved: …
  - 🐛 Fixed: … (thanks for the report <@userId>)
  ```

- Feedback triage: `feedback --days 7` → bugs with repro status and cause, ideas grouped by 👍 count. Replies and tags only after the owner confirms.
- Members' personal info and data never leave this server.
