# 이 서버 운영 메모

> Claude 가 이 서버에서 일하기 전에 읽는 메모예요. 서버에 맞게 자유롭게 고치세요.

- 말투: 친근한 존댓말(~해요). 이모지는 줄 머리에 하나 정도.
- @everyone 알림: 공지 채널에서만, 운영자가 말할 때만.
- 테스터 초대: `invite --note "이름 (어디서 왔는지)"` — 링크 전달은 운영자가 직접.
- 업데이트 로그 형식:

  ```
  ### 🚀 YYYY-MM-DD 업데이트
  - ✨ 새로: …
  - 🛠️ 좋아짐: …
  - 🐛 고침: … (제보 고마워요 <@유저ID>)
  ```

- 피드백 정리: `feedback --days 7` → 버그는 재현 여부와 원인, 제안은 👍 수로 묶어서 보고. 답글·태그는 운영자 확인 뒤.
- 멤버의 개인 정보·데이터는 서버 밖(글감·보고서)으로 옮기지 않아요.
